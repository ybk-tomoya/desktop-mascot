# 虹夏のデザインで決まっていること

参考資料は `references/` の三面図。ユーザーと合意済みの点:

- 3頭身。顔と目は大きめ
- サイドテールは正面から見て右（本人の左）。右向きでは奥に隠れて影色、左向きでは手前に見える
- アホ毛は頭に接した直角三角形（浮かせない、二等辺三角形にしない）。頭・サイドテールとは輪郭線で分ける
- 正面に後ろ髪の塊は描かない（頭の形・前髪・顔横の毛束・サイドテールのみ）
- 横向きの後ろ髪は肩くらいまで。頭は胴体の真上（前に出すと猫背に見える）
- 目は白目・瞳孔・ハイライトありのアニメ塗り。ジト目に見えないよう上まつ毛は1段。横向きの目も同じ部品で揃える
- ほっぺは薄ピンク（`p`）
- 足はまっすぐで、太ももから足首へゆるく細くなる形。ふくらはぎの膨らみやひざのくびれは入れない
- 制服: 白シャツ、大きな赤いリボン、黒いプリーツスカート、白い靴下、赤い靴
